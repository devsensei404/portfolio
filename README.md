# Portfolio

Minimal dark portfolio site for Subhadeep Paul ([@devsensei404](https://github.com/devsensei404)), built with plain HTML and CSS. No frameworks, no build step.

**Live site:** https://your-subdomain.is-a.dev (coming soon)

This is a placeholder portfolio. A full rebuild is planned once I've learned frontend properly.

## Sections

About, Projects, Experience, Education, Skills, Interests and Contact.

## Structure

```
portfolio/
├── index.html
├── assets/
│   └── photo.jpg
├── README.md
└── .gitignore
```

## Run locally

Clone the repo and open `index.html` in your browser. Fonts load from Google Fonts, so you need an internet connection.

```bash
git clone https://github.com/devsensei404/portfolio.git
cd portfolio
```

## Deployment

Hosted on Vercel as a static site: framework preset "Other", no build command, root directory as the output.
